

# DỰ ÁN THỰC HÀNH QUẢN LÝ PHIÊN BẢN

## 1. Giới thiệu
Đây là dự án thực hành sử dụng GitHub Desktop
để quản lý và theo dõi các thay đổi của tài liệu.

- Thực hành commit, branch và push.
- Rèn luyện kỹ năng quản lý phiên bản.

## 3. Công cụ sử dụng
- GitHub
- GitHub Desktop
- Visual Studio Code (nếu cần)
